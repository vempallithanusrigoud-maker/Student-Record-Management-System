Student Record Management System

About

A Python application to manage student records.

Features

- Add student records
- View all student records
- Search students by ID or name
- Update student details
- Delete student records
- Save records using JSON
- Validate student ID and GPA

Technologies Used

- Python 3
- JSON

How to Run

1. Install Python.

2. Open the project folder in Visual Studio Code.

3. Open the terminal.

4. Run this command:
   
   "python student_management.py"

Files

- "student_management.py" - Main Python program
- "students.json" - Stores student records
